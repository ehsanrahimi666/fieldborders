# Candidate spectral features

Defines the per-date features whose temporal contrast across field
borders is ranked by
[`fb_rank_contrast()`](https://ehsanrahimi666.github.io/fieldborders/reference/fb_rank_contrast.md).
The default set, used to develop and validate the method, holds the
bands and the normalised differences of all band pairs,
`(a - b) / (a + b + 1e-4)`. With `set = "svid"`, published spectral
indices from the catalogue of the `svid` package (and, optionally,
expressions generated by an `svid` grammar) that can be computed from
the available bands are added.

## Usage

``` r
fb_feature_set(bands, set = c("nd", "svid"), grammar = NULL)
```

## Arguments

- bands:

  Band names of the stack (Sentinel-2 names such as `"B04"`).

- set:

  `"nd"` (bands and normalised differences) or `"svid"`.

- grammar:

  Optional `svid_grammar` object whose expressions are added when
  `set = "svid"`; keep it small, because every expression is ranked.

## Value

A data frame with columns `name`, `expr` (an R expression in the band
names) and `type` (`"band"`, `"nd"`, `"svid"`).

## Examples

``` r
fs <- fb_feature_set(c("B02", "B03", "B04", "B08"))
fs
```
