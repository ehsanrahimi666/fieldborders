# Acquisition dates of a stack

Acquisition dates of a stack

## Usage

``` r
fb_dates(x)
```

## Arguments

- x:

  An `fb_stack`.

## Value

A `Date` vector.

## Examples

``` r
fb_dates(fb_example_stack("california"))
#>  [1] "2024-01-29" "2024-02-28" "2024-03-19" "2024-04-28" "2024-05-28"
#>  [6] "2024-06-27" "2024-07-27" "2024-08-31" "2024-09-30" "2024-10-20"
#> [11] "2024-11-29" "2024-12-04"
```
